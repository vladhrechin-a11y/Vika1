# Перукарня Вікторія — демонстраційний PWA

## Що є в демоверсії
- клієнтська сторінка з послугами, цінами, галереєю-заглушкою та відгуками;
- форма заявки на запис;
- тестовий кабінет адміністратора: перегляд заявок, зміна статусів, редагування послуг, модерація відгуків;
- PWA manifest, іконка та Service Worker.

## Запуск
Для перевірки відкрийте сайт через локальний вебсервер або опублікуйте файли в GitHub Pages.
У GitHub: Settings → Pages → Deploy from a branch → main → /(root).

## ВАЖЛИВО — це прототип, не production
У демоверсії дані зберігаються в localStorage конкретного браузера. Тому заявки з телефону клієнта НЕ надходять на пристрій майстра. Демонстраційний пароль також не є захистом для реального використання. Перед реальною публікацією для клієнтів потрібно під'єднати Supabase: автентифікацію адміністратора, таблиці послуг/заявок/відгуків, правила RLS та серверну перевірку конфліктів часу. Не використовуйте демоверсію для реальних персональних даних чи записів.

## Орієнтовний прайс
Ціни — стартові демонстраційні значення, а не затверджений прайс Вікторії. Перед публікацією для клієнтів їх треба погодити з майстром.
